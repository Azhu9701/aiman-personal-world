AIMAN PERSONAL WORLD / AGENT ACCESS

选好范围，再让 Agent 读懂

这次交给 Agent 的是实际消息，不只是页面链接。你决定哪段聊天可以用，Agent 才能搜索原话、查看上下文、整理结论。

授权前请读：点击“建立分析选区”只把所选范围交给本机 Harness 暂存。Agent 每次读取还会经过 Harness 的授权服务；读取结果可能发送给当前模型服务商，并保存在会话日志中。插件不会发送微信、接受邀请或写外部日历。撤销不能删除已经返回给模型的内容。

1 · 选择你导出的会话

在 Personal World 的微信历史里打开一个会话，选择“导出 JSON”。在此选择这个文件；此时只在浏览器内预览，不会立即上传。只支持单个会话的 Personal World JSON 导出，不接触原始微信数据库。



2 · 确认范围与用途
最多 500 条消息，每个选区有效一小时；单次最多 20 条／48 KiB，总读取上限 256 KiB。选区只保存在插件内存中，Harness 重启后失效。模型首次获准读取后，选区绑定到该 Agent。





3 · 把任务交给 Harness
复制下方任务到 Harness 对话。Agent 会调用真实消息工具，并在首次及后续读取时请求本次授权。未授权不会返回消息。
