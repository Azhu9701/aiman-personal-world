# 路线图

路线图是方向，不是已实现能力或交付日期承诺。v0.2.0 的功能以 [README](../README.md)、[API](api.md) 和实际源码为准。

## 当前：可回看证据的个人工作空间

已有规范归档导入、聊天历史、本地关键词与规则候选、时间线、会话范围内的发送者与主题图谱、人工复核和模板草稿。所有关联保留消息依据，未知和截断范围可见。

微信适配器在已有可用密钥的条件下读取兼容的本地数据快照，尝试映射已存在媒体。刷新由用户手动发起，执行完整管线；没有自动取钥、持续增量同步或云推理。

## 接下来：更好的可验证性

候选应该更容易解释、排除公告和否定误报，并完整呈现跨时间的反例。任何新规则都需要人工数据测试，尤其是同主题不同项目、同名不同人、已完成、取消、电话或线下推进的反例。

优先增强证据版本、规则版本、变化原因和审计范围的表达，而不是把关键词排序包装成概率或事实。更好的媒体兼容、明确的系统支持矩阵和可复现依赖安装也属于后续工作。

增量刷新、应用级静态加密、细化的本机权限、可选本地语义检索和实体消歧尚未实现。若增加模型，应明确模型来源、输入范围、运行位置、失败状态和证据回溯；本地模式不能因此暗中上传私人内容。

## 未来：连接公开 AIMAN Robotics / Manufacturing 世界

预期用途是把私人讨论中的待核实需求，与**独立的公开证据**所支持的产品、技术、制造能力或市场事实进行比对。当前版本没有此连接器、公开事实库或发布接口。

设计前提包括：

- 公开事实保留公开来源、引用位置、观察时间和失效条件。
- 私人聊天、关系、评价和草稿始终在私人边界内；共享需要确切内容预览和用户明确决定。
- “某消息提到某产品”与“该产品当前具备某能力”采用不同证据链。
- 冲突、过时信息和不可核实内容可见，不让图谱链接自动变成事实。
- 联系第三方或采取现实行动始终需要用户决定；不新增自动联系或个人可信度评分。

六问题定义见 [WORLD.md](../WORLD.md)。

## 本轮已落地（v0.1.1）

草稿标题/正文持久保存、修改历史和并发冲突保护；复核状态与关联线索联动；刷新后既有工作记录保留及失效来源提示。持续增量同步、更多历史来源、本地语义检索、项目实体和应用级加密仍是后续任务。

## 本轮已落地（v0.2.0）

分批历史导入、先预览后确认、独立来源标识、保守去重/冲突处理、累积快照合并、增量索引写入、按月覆盖、来源快照和进程中断恢复。更早历史是否实际出现仍取决于用户提供的本机/旧电脑/手机导出资料。原生采集后台增量、本地语义检索、删除/遗忘与应用级加密仍待实现。

## 本轮已落地（v0.3.0）

主来源本人文本的关注与自述线索、按月份观察、本人确认与修订、证据回溯、排除和删除、明确选中的介绍预览。完整语义画像、思想演化推理、跨来源本人身份认证以及加密保险箱仍未实现。
