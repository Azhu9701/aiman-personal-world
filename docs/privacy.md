# 隐私、访问和数据保存

## 当前承诺的范围

v0.1.0 把用户选定的归档、查询索引、可打开媒体、复核与草稿保存在本机。内置应用没有遥测、云模型请求、自动外站检索、媒体网络下载或向联系人发送消息的路径。演示使用完全人工的数据。

浏览器和 Python 服务之间会通过本机 HTTP 通信。用户主动点击原消息中的外部链接时，浏览器会访问相应外站；手动安装依赖、下载源码或使用 GitHub 属于用户另行发起的网络操作。不要把“默认本地”理解为这台电脑绝不会联网。

## 保存什么

| 数据 | 用途 | 隐私属性 |
|---|---|---|
| 原有消息归档 | 可追溯的导入来源与导出清单 | 可能包含完整聊天、内部 ID、解码和来源统计 |
| `index.sqlite` | 聊天浏览、搜索、规则计算 | 包含可直接查询的文本、显示名、时间与媒体引用 |
| `media/` | 已有图片、语音、视频、文件和头像的可读副本 | 可能比原加密缓存更容易直接读取 |
| `workspace.sqlite` | 本人的复核、备注和草稿 | 包含私人判断、计划及引用的证据 |
| 配置与访问凭据 | 连接用户指定来源及本机浏览器 | 可暴露本机位置或赋予当前工作空间访问权 |
| 用户下载的导出与草稿 | 本机查看或用户自行处理 | 是新的私人文件，不会自动继承状态目录权限 |

已有数据库密钥保留在用户选定的文件中；配置引用其位置，不把密钥放进网页或公开文档。部分导入处理需要将密钥放入本机进程内存；操作系统和具有本机同等权限的软件仍属于信任边界。

## 没有应用级静态加密

**本版没有对归档、索引、媒体或工作状态做应用级静态加密。** POSIX 系统上，程序为私人状态目录设置 `0700`，为自己创建的私有文件设置 `0600`，并检查重要配置的属主和权限。Windows 的 Python 文件权限语义不同；本项目尚未实现独立的 Windows ACL 加固工具。

这些措施不能保护已解锁账号免受同用户恶意程序、管理员权限、恶意浏览器扩展、屏幕录制或复制后的备份访问。可按环境启用 FileVault、BitLocker 等系统磁盘加密；项目不会代为启用，也不声称已启用。

请自行选择私人状态目录。放在网盘同步目录、共享主目录或自动备份范围内，可能由操作系统或其他软件复制数据，本项目无法阻止这些外部行为。清理一个状态目录也不等于清理浏览器下载、剪贴板、备份和原数据。

## 浏览器访问边界

服务只监听回环地址，默认端口为 `18792`。它检查 Host，并使用每个状态目录独立的会话 Cookie；Cookie 为 HttpOnly、SameSite=Strict。保存复核和草稿还需要准确的同源 `Origin`。

启动连接可能短暂使用带凭据的本机 URL，随后重定向到不带凭据的页面。不要复制该启动链接或凭据文件到公开聊天、工单、终端录屏或其他站点。服务关闭常规请求日志，避免搜索词和启动凭据写入访问日志。

页面将消息当文本构建，媒体引用限于本机缓存路径；文件附件作为下载提供，不把消息 HTML 当作可信脚本执行。应用还设置内容安全策略和禁止外站嵌入等响应头。这些是边界控制，不是经过形式证明的安全保证。

本版没有公网或多人服务的身份与授权模型。不要通过反向代理、公网绑定或端口转发分享真实工作空间。同一浏览器来源下运行的其他不可信代码、扩展及同用户本机程序仍需由用户管理。

## 判断、草稿和公开事实

规则分数不是个人信用分。图谱中的显示名不自动变成确认身份；共享主题不自动证明能力、合作关系或可用产能。人工备注只是工作状态。

当前没有公开世界写入功能。未来公开连接的前提应是：公开事实有可引用的公开证据，用户可以预览确切发布内容，并明确决定是否发布。私人聊天与私人判断不作为自动公开材料。

## 提交问题时

只提交人工复现数据和经过检查的摘要。不要上传数据库、密钥、访问凭据、真实归档、完整日志、未遮盖的截图或他人的聊天。发布扫描器只能挡住部分常见泄漏类型，不能判断任意一段文字是否来自私人记录。

遇到访问绕过、数据泄漏或敏感材料误发布，请依照 [安全报告](../SECURITY.md) 先选择私密渠道。
