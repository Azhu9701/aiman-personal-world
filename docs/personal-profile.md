# 个人画像 · 本人可维护的协作资料

v0.3.0 增加独立的 `/profile` 页面，从工作台左侧“个人画像”进入。

## 实际能做什么

- **我在聊什么**：固定非敏感主题词表的消息数、出现天数、原始样本和月份分布。月份表同时显示命中数及每百条有效本人文本的占比，避免把记录多简单当成偏好更强。一个文本可能命中多个主题；话题出现不等于赞同，更不是能力分数。
- **待我核对的自述**：用中文第一人称规则提取原句，按“指令、身份、职业、项目、偏好”分类。保留否定、时间和原有措辞；同一原句的出现次数、天数和证据样本可查。近期一次想法也可能命中，因此不能自动认定为长期原则。
- **我认可的介绍**：逐项检查原话和上下文，修改文字或类别，主动确认后保存到本机。原句与本人修订分开；确认仅说明本人认可该表述，不是软件认证。
- **分享准备**：本人勾选确认条目，先预览，再复制或下载文本。输出按五类及原句最早出现时间排序，并分别标注原句日期与本人确认日期，不把今天的修订假装成当年的原话；不附带聊天上下文、会话名、消息编号或原始证据链接。它可作为其他 AI 的协作背景，但本程序不会替你发送。

程序仍是规则整理器，不包含模型推理、MBTI、心理诊断、可信度分数或自动思想变化判断。月份分布是表达变化的观察入口，不是思想演化结论。

## 谁的消息会被使用

只读取现有索引里 `is_self=1`、`type=text`、有效正时间戳且消息与会话都不属于 `pw:` 其他来源命名空间的记录。主来源 primary 的“本人”身份取决于导入时的身份标记，不是新增的身份认证。不要把别人的导出误标为本人的 primary 来源。

最多读取最近 50,000 条满足上述条件的文本；达到限制明确显示截断。会话排除、长度限制、明显引用/转发/假设、联系人或凭据样式、敏感领域词表会进一步过滤。主题样本最多五条，自述样本最多八条（覆盖最早和近期例子），初始最多返回200个候选，按重复天数、最近时间排序。

过滤是可检查的保守启发式，不是完美脱敏，可能误排除，也可能遗漏隐晦引用、玩笑、复制文章或敏感内容。本人发送不等于本人创作或长期立场。画像不能代表没有保存的经历。图片、语音、文件正文以及身份未知消息不参与本版画像。

## 修改与来源变化

画像操作采用全局递增 `revision`；不同窗口的过期保存会返回冲突而不是覆盖。合并归档与画像写入共用状态锁，保存前后还检查源索引版本。增加或更改支撑原句的消息会使旧确认需要重核；来源缺失、读取上限导致无法定位或会话停用时也暂停导出，保留已有人工表述。

“原始证据”使用已有证据接口，明确点击后才展示同会话上下文，可能包含对方消息。对方发言仅作核对背景，不作为本人画像的自动生成来源。

## 排除和删除的边界

“暂不采用”保留条目供以后重新核对；“不使用这个会话”会阻止其文本进入画像分析，关联确认项暂停导出，可以恢复会话参与。

“删除这条”从本功能当前记录中去掉保存的文字和证据列表，仅保留不含原文的条目摘要编号以阻止相同原句再次成为自述候选。不同原句仍可能再次出现；话题统计不会因单条删除而删减，可排除整个会话阻止它参与分析。此处删除不删除聊天归档、输入快照、原程序备份、系统备份、剪贴板或已经下载的介绍。不宣称取证级物理擦除。

人工记录单独保存为私有 `profile-state.json`，读取画像本身不创建这个文件。画像无应用级静态加密、不保存自动候选到磁盘、不使用浏览器 localStorage，不调用云模型。保存采用文件原子替换，不建立画像修改历史。未保存的编辑没有崩溃恢复；分享前请检查文字中是否仍有不应共享的信息。

## 本地接口

`GET /api/profile`：覆盖、主题、月份、自述候选、人工条目、来源状态、排除会话及当前revision。仅本机会话可以读取，无原始私聊日志输出。

`POST /api/profile/update`：操作为 `confirm`、`dismiss`、`delete`、`exclude_conversation` 或 `include_conversation`，都需要 `expected_revision`。确认和排除候选须带 `id` 和 `source_fingerprint`，确认可以提供 `text`（最多400字）与五类之一的 `category`。会话操作使用 `conversation_id`。删除不要求当前来源还存在。

`POST /api/profile/export`：必须明确给出1–100个 `ids` 及 `expected_revision`，仅返回本人确认、来源仍匹配且当前未排除条目的文本预览。任何一个不合格条目都会拒绝整次导出，不静默漏项。接口继承本机身份验证、严格同源写入和大小限制；过期版本返回409 `profile_conflict`，证据变化返回409 `source_changed`。

本版人工条目上限1000、排除会话上限1000、抑制条目上限10000。来源/规则读结果保留不确定性，服务器不对同名跨账号进行身份猜测。

## 用人工数据体验与验证

`examples/profile-demo.json` 是明确标记的手写正反例，不是用户画像。可以导入一个**独立**目录体验：

```sh
python3 personal_world.py import examples/profile-demo.json --state /path/to/profile-demo
```

真实浏览器检查通过已有的独立临时 Chromium 配置运行，不连接个人浏览器会话：

```sh
PYTHON=python3 CHROME_BIN=/path/to/chrome node scripts/test_profile_browser.mjs
```

Python 用例在 `test_personal_profile.py`，覆盖本人/他人/未知/其他来源隔离、规则过滤、原句保留、确认修改、过期和并发、导出选择、删除、会话排除及HTTP授权边界。浏览器用例只处理人工示例。
